## Vietnamese lunar reference data

Production lunar data is not yet included. Before adding generated or transformed reference data, record its source, retrieval or generation date, UTC+7 convention, checksum, license status, and any required attribution in `ReferenceData/README.md` and this notice.

Curated URLs in `docs/VietLunar_TEST_VECTORS.json` are validation references; they do not grant permission to redistribute copied source code or datasets.

The source catalog currently records material by Hồ Ngọc Đức, Edward M. Reingold and Nachum Dershowitz, and Hermetic Systems as rules or comparison references. Their source code and prepared datasets are not bundled. See `ReferenceData/README.md` and `ReferenceData/source-catalog.json` for exact roles and URLs.
